核心配置

allowlist：只有启用群响应；blocklist：除屏蔽群外都响应。

多个前缀用英文逗号分隔；留空会自动使用 ~。

开启后，群成员 @ bot 的消息会进入回复逻辑；关闭后只响应前缀和免前缀规则。

默认 10%；只影响“免前缀关键词应答”。吃什么/csm 等免前缀 Lua、前缀指令、@ 触发不受影响。

群限流控制同一群两次 bot 回复的最小间隔；用户上限控制单个用户每分钟最多触发次数。填 0 表示关闭对应限流。

allowlist 模式下，只有这些群会响应。

blocklist 模式下，这些群会静默；allowlist 模式下也可用于显式屏蔽。

管理员可以使用 /bot 控制命令；网页写操作仍由 Admin token 控制。
