OneBot 11 API 参考

当前项目保留 OneBot 11；OneBot 12 需要协议端明确支持，LLBot 当前链路建议继续使用 OneBot 11。

群里发送 ~指令 参数 时，会执行 scripts/lua/指令.lua；Lua 里可读取 event.command、event.args、event.full_message。

Lua 可用封装接口，也可以用原始 action 名通过 api.call(action, params) 调用。

api.get_group_list()
api.get_group_info(group_id)
api.get_group_member_list(group_id)
api.get_group_member_info(group_id, user_id)
api.get_login_info()
api.get_stranger_info(user_id)
api.send_group_message(group_id, message)
api.send_private_message(user_id, message)
api.reply(message)
api.get_state(key, namespace)
api.set_state(key, value, namespace)
api.delete_state(key, namespace)
api.url_encode(value)
api.http_get_json(url)
api.call("send_group_msg", {
  group_id = event.group_id,
  message = "hello"
})

脚本入口

function on_command(event, api)
  return "收到参数：" .. event.args
end

常用原始 action

  • send_private_msg：发送私聊消息
  • send_group_msg：发送群消息
  • send_msg：发送消息
  • delete_msg：撤回消息
  • get_msg：获取消息
  • get_login_info：获取登录号信息
  • get_stranger_info：获取陌生人信息
  • get_friend_list：获取好友列表
  • get_group_list：获取群列表
  • get_group_info：获取群信息
  • get_group_member_info：获取群成员信息
  • get_group_member_list：获取群成员列表
  • set_group_kick：群组踢人
  • set_group_ban：群组禁言
  • set_group_card：设置群名片
